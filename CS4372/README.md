`cnn.py` brings in the intel data from the Kaggle URL source using the keras
dataloader, downloads the `ResNet50`, and runs the experiments to find the best
fine tuning parameters. 

This script was ran with a local uv environment, an untested GoogleColab copy
can be found [here](https://colab.research.google.com/drive/1AE-2UALEEyX86yvTDdW93JtBom9je8R0?usp=sharing)
